# PvZ Terminal

Небольшая стратегия в терминале: строй защиту из растений и удерживай пять рядов от зомби.

## Запуск

Нужен Python 3.12 или новее и терминал с поддержкой `curses`. На Linux и macOS достаточно стандартной библиотеки Python: устанавливать игровые зависимости не требуется.

```bash
python3 pvz.py
# Альтернативный запуск из папки проекта:
python3 -m pvz
```

Чтобы использовать виртуальное окружение:

```bash
python3 -m venv .venv
source .venv/bin/activate
python -m pvz
```

## Управление

| Клавиша | Действие |
| --- | --- |
| W, A, S, D | Перемещение по полю 9 × 5 |
| 1, 2, 3, 4 | Горохострел, подсолнух, орех, чавкер |
| Пробел | Посадить выбранное растение |
| R | Выкопать растение |
| P | Пауза |
| Q | Выход |

Начальный запас: 300 солнц. Подсолнух даёт 25 солнц раз в четыре игровые секунды. У каждого растения есть цена и время восстановления после посадки. Зомби, добравшийся за левый край поля, завершает игру.

## Повторяемые партии

```bash
python3 -m pvz --seed 42 --tick-ms 200
```

`--seed` фиксирует генератор случайных чисел. `--tick-ms` задаёт длительность игрового тика в миллисекундах. Справка доступна через `python3 -m pvz --help`.

## Разработка

Игровая логика находится в `pvz/game.py`, сущности в `pvz/types.py`, баланс в `pvz/constants.py`. Изменения удобно проверять на фиксированном seed и отдельно проходить игру в терминале.

Это самостоятельная учебная мини-игра. Проект не связан с авторами оригинальной Plants vs. Zombies.
