# Шахматный газон

Для посадки доступны клетки одного цвета шахматной доски. Соседние ряды требуют разных позиций.

Цель: Выстроить огонь и экономику на доступных клетках.

## Правила

- Начальное солнце: **600**.
- Ряды в игре и этой инструкции нумеруются сверху от 1 до 5; в JSON используется 0–4.
- Победа: дождаться окончания последней волны и уничтожить всех оставшихся зомби.
- Газонокосилок нет: первый прорыв сразу означает поражение.
- Закрытые для посадки клетки: ряд 1: колонки 1, 3, 5, 7, 9; ряд 2: колонки 2, 4, 6, 8; ряд 3: колонки 1, 3, 5, 7, 9; ряд 4: колонки 2, 4, 6, 8; ряд 5: колонки 1, 3, 5, 7, 9. Зомби проходят через них свободно.
- Начальная расстановка: SUNFLOWER — ряд 2, колонка 1.

Доступные растения: PEASHOOTER, SUNFLOWER, REPEATER, WALL_NUT, CHERRY_BOMB.

## Тактика

В нечётных рядах можно начать стрелков со 2-й колонки, в чётных — с 1-й или 3-й. Сначала проверь доступность клетки, затем строй нужный ряд. Для бомбы важно, что закрыт и сам центр посадки: соседняя доступная клетка изменит охваченный квадрат.

## Что проверяет уровень

Рельеф чередуется по рядам и не допускает копирования одной позиции на всё поле. Площадной урон тоже требует доступного центра, а не только подходящей группы врагов.
