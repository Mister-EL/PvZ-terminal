# Неравные окна

Единственная площадка каждого следующего ряда расположена ближе к врагу. Дистанции по рядам различаются.

Цель: Выбрать очередь для быстрого тыла и контактную защиту ближе к входу.

## Правила

- Начальное солнце: **900**.
- Ряды в игре и этой инструкции нумеруются сверху от 1 до 5; в JSON используется 0–4.
- Победа: дождаться окончания последней волны и уничтожить всех оставшихся зомби.
- Пассивное солнце отключено: доход дают только подсолнухи и явно указанные бонусы волн.
- Запас солнца ограничен **900**: трать доход до заполнения хранилища.
- Одновременно на поле не более **5** растений. Временные бомбы и мины тоже занимают место до исчезновения.
- Газонокосилок нет: первый прорыв сразу означает поражение.
- Закрытые для посадки клетки: ряд 1: колонки 1, 3, 4, 5, 6, 7, 8, 9; ряд 2: колонки 1, 2, 4, 5, 6, 7, 8, 9; ряд 3: колонки 1, 2, 3, 5, 6, 7, 8, 9; ряд 4: колонки 1, 2, 3, 4, 6, 7, 8, 9; ряд 5: колонки 1, 2, 3, 4, 5, 7, 8, 9. Зомби проходят через них свободно.

Доступные растения: REPEATER, CHOMPER, SNOW_PEA.

## Тактика

Длинные верхние направления выдерживают очередь против пачек бегунов. В нижних коротких рядах хищник убирает ведро при контакте, когда дальняя линия уже потеряла бы цель. Каждая площадка единственная: дополнительное растение или барьер рядом поставить нельзя.

## Что проверяет уровень

Разная дистанция сочетается с разными составами атак. Одинаковое растение во всех рядах теряет либо темп против быстрых групп, либо возможность добить тяжёлую цель до контакта.
