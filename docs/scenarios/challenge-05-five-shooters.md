# Пять стрелков

По стрелку в каждом ряду уже есть. Остались два усиления на всё поле.

Цель: Выбрать нужные ряды для ограниченного подкрепления.

## Правила

- Начальное солнце: **200**.
- Ряды в игре и этой инструкции нумеруются сверху от 1 до 5; в JSON используется 0–4.
- Победа: дождаться окончания последней волны и уничтожить всех оставшихся зомби.
- Пассивное солнце отключено: доход дают только подсолнухи и явно указанные бонусы волн.
- Запас солнца ограничен **200**: трать доход до заполнения хранилища.
- Начальная расстановка: PEASHOOTER — ряд 1, колонка 2, PEASHOOTER — ряд 2, колонка 2, PEASHOOTER — ряд 3, колонка 2, PEASHOOTER — ряд 4, колонка 2, PEASHOOTER — ряд 5, колонка 2.

Доступные растения: PEASHOOTER.

## Тактика

Единственные два дополнительных горохострела нужны во 2-м и 4-м рядах: туда идут повторные конусы. Первый ряд уже держит обычных врагов без подкрепления. Усиливай по расписанию, а не по тому, где враг появился первым.

## Что проверяет уровень

Готовая равномерная линия и ограниченное подкрепление превращают чтение следующей волны в основную задачу. Выбор колоды здесь исключён: важны размещение и приоритет.
