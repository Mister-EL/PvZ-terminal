# Коридор взрыва

Для бомбы доступны три клетки по центру, для мин — две фланговые площадки. Остальной газон закрыт.

Цель: Дождаться подхода групп к доступной зоне взрыва.

## Правила

- Начальное солнце: **650**.
- Ряды в игре и этой инструкции нумеруются сверху от 1 до 5; в JSON используется 0–4.
- Победа: дождаться окончания последней волны и уничтожить всех оставшихся зомби.
- Пассивное солнце отключено: доход дают только подсолнухи и явно указанные бонусы волн.
- Запас солнца ограничен **650**: трать доход до заполнения хранилища.
- Одновременно на поле не более **3** растений. Временные бомбы и мины тоже занимают место до исчезновения.
- Газонокосилок нет: первый прорыв сразу означает поражение.
- Закрытые для посадки клетки: ряд 1: колонки 1, 2, 3, 4, 6, 7, 8, 9; ряд 2: колонки 1, 2, 3, 4, 5, 6, 7, 8, 9; ряд 3: колонки 1, 2, 3, 4, 8, 9; ряд 4: колонки 1, 2, 3, 4, 5, 6, 7, 8, 9; ряд 5: колонки 1, 2, 3, 4, 6, 7, 8, 9. Зомби проходят через них свободно.

Доступные растения: POTATO_MINE, CHERRY_BOMB.

## Тактика

Две минные площадки закрывают отдельные крайние ряды. Центральную группу можно накрыть из 7-й колонки центра после первого шага к 8-й колонке. Поставить вишню рядом с точкой появления запрещено: дождись доступного общего радиуса.

## Что проверяет уровень

Ограниченные площадки задают конкретные зоны применения разных взрывов. Лимит трёх растений оставляет по месту для обеих мин и короткой центральной бомбы.
