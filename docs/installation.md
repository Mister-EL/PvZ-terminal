# Установка и запуск

Нужен Python 3.12 или новее со стандартным модулем `curses`. Игра рассчитана на Linux
и macOS, интерактивный терминал и окно от 76×24 символов. Внешних библиотек у игры
нет. Стандартная сборка Python для Windows не содержит `curses`.

## Из исходников

В каталоге репозитория:

```bash
python3 -m pvz --list-scenarios
python3 -m pvz
```

## Установленный пакет

Создайте виртуальное окружение и установите checkout. `setuptools` и `wheel` нужны
только для сборки, а не для игры. При обычной установке pip может получить их из
индекса пакетов:

```bash
python3 -m venv .venv
.venv/bin/python -m pip install .
.venv/bin/pvz-terminal --list-scenarios
.venv/bin/pvz-terminal
```

Команда `pvz-terminal` и `python -m pvz` принимают одинаковые параметры. После
установки их можно запускать из любого каталога; JSON всех сценариев находится
внутри пакета.

## Сборка и установка без сети

Если в выбранном Python уже есть `build`, `setuptools>=68` и `wheel`, можно
собрать wheel без загрузки зависимостей:

```bash
python3 -m build --wheel --no-isolation
.venv/bin/python -m pip install --no-index --no-deps dist/pvz_terminal-0.2.0-py3-none-any.whl
```

В wheel входят только пакет `pvz` и сценарии `campaign-*.json` / `challenge-*.json`.
Тесты, Git, личные сохранения и исходные доказательства прохождения туда не входят.

## Один файл `.pyz`

Для сборки архива достаточно стандартной библиотеки Python, без pip и сборочных
пакетов. Сначала посмотрите состав, затем выберите свободный путь назначения:

```bash
python3 tools/build_zipapp.py --dry-run --output dist/pvz-terminal.pyz
python3 tools/build_zipapp.py --output dist/pvz-terminal.pyz
python3 dist/pvz-terminal.pyz --list-scenarios
python3 dist/pvz-terminal.pyz
```

Полученный файл можно перенести в другой каталог или на другой компьютер с
подходящим Python и `curses`. Распаковка не требуется: сценарии читаются прямо из
архива через `importlib.resources`. На Linux/macOS архив также исполняется напрямую:
`./dist/pvz-terminal.pyz`.

Сборщик включает явный список модулей игры и только JSON сценариев. Он показывает
тот же список в `--dry-run`, который ничего не записывает. Новые модули игры нужно
добавлять в `RUNTIME_FILES` сборщика. Ссылки на внешние файлы в составе приложения
отклоняются.

Сборка идёт во временном каталоге рядом с выходным файлом. Готовый архив появляется
атомарно; существующий файл или символическая ссылка не заменяются. Для повторной
сборки задайте новое имя. Файловая система назначения должна поддерживать жёсткие
ссылки. При одинаковом содержимом и окружении Python две сборки дают одинаковые байты.

## Прогресс

Прогресс хранится в `$XDG_STATE_HOME/pvz-terminal/progress.json`, а при отсутствии
абсолютного `XDG_STATE_HOME` — в `~/.local/state/pvz-terminal/progress.json`.
Параметр `--progress-file /путь/к/progress.json` задаёт другой файл; `--no-save`
отключает запись прогресса. Просмотр списка сценариев не создаёт сохранения.
